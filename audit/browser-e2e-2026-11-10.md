## Příčina blokace a provedení

Místní Chromium se znovu nepodařilo spustit: končí před otevřením stránky na `process_singleton_posix.cc:297: socket() failed: Operation not permitted (1)`; crashpad hlásí také `ptrace: Operation not permitted (1)`. Tato místní překážka trvá. Ověření bylo dokončeno ve skutečném Chromium **141.0.7390.37** pomocí Playwright 1.56.1 na GitHub Actions / Ubuntu 24.04. Prohlížeč načítal úplný checkout webu z místního HTTP serveru a používal skutečné pole, tlačítko, Enter a reset. Nebyl použit jsdom, simulované rozložení ani přímé volání odpovědní funkce.

První úplný běh skončil 84 PASS / 12 FAIL / 0 BLOCKED. Všech 12 selhání bylo v HU na mobilu: nastavený viewport 393×873 se kvůli přesahujícím dlouhým slovům v kompaktních úvodních kartách projevil jako `innerWidth=412`, `innerHeight=916`, zatímco šířka dokumentu/zařízení byla 393. Obsah odpovědí, kontext a ostatní kontrolovaná geometrie prošly.

Oprava `html[lang="hu"]` při šířce do 650 px doplňuje pro nadpisy a odstavce karet `min-width:0; overflow-wrap:anywhere`. Zachovává dvě karty vedle sebe. Zdravotní texty ani odpovědní logika se nezměnily. Oprava nezasahuje do ostatních jazyků ani desktopu.

Následný cílený retest opakoval pouze 12 selhaných HU mobilních variant: **12 PASS / 0 FAIL / 0 BLOCKED**, všech 18 otázek s reálnou geometrií **393×873**, bez vodorovného přesahu a bez chyb JavaScriptu. Screenshot po opravě byl vizuálně zkontrolován. Předchozích 84 PASS zůstalo převzato; rozsah CSS opravy je mimo jejich kombinace jazyka a viewportu.

## Co bylo ověřeno

- Alkohol → navazující dotaz na diabetes 2. typu.
- Vysoký cukr → jednotky → obecný postup.
- HbA1c → měření → četnost → opakovaná otázka (také Enter).
- Rozdíl diabetu 1./2. typu, CGM a glukometr, TIR.
- Nízká glykemie s třesem, bezvědomí, vysoká glykemie se zvracením a bolestí břicha.
- Odmítnutí individuální dávky inzulinu, nevysazování metforminu svévolně, THC.
- Reset mezi rozhovory, jazyk stránky, skutečný vznik nové odpovědi, absence návratu do běžného vyhledávání.
- Přesné rozměry, začátek aktuální odpovědi v logu, Nový rozhovor a pole mimo překrytí hlavičkou, absence vodorovného přesahu, chyby JavaScriptu.
- Doslovné odpovědi a odkazy jsou uloženy v JSON artefaktech.

Kontroly obsahu jsou funkční očekávání tohoto auditu; nejde o nezávislou klinickou revizi. Mobilní režim znamená skutečný prohlížeč s mobilní emulací; hardwarový Android a jeho systémová klávesnice nebyly testovány. Externí stránky nebyly v této navazující matici znovu otevírány.
