DIAKOMPAS 2.5.2 – GITHUB PAGES

INSTALACE
1. Rozbalte ZIP.
2. Nahrajte OBSAH rozbalené složky (ne samotnou složku ani ZIP) do kořene repozitáře github.com/diakompas/diakompas na větev main.
3. Musí být přítomny index.html, style.css, složky cz/, sk/, en/ a ostatní soubory.
4. V Settings > Pages ponechte Deploy from a branch / main / (root).
5. Otevřete https://diakompas.github.io/diakompas/ a ověřte odkazy a jazykové verze.

DŮLEŽITÉ: Nahrání samotného index.html NESTAČÍ. Web 2.5.2 je vícesouborový.

OBSAH: 6 témat ve 3 jazycích, 18 samostatných stránek článků, 3 jazykové rozcestníky, o projektu, soukromí, vlastní SVG ilustrace, responzivní design, lokální vyhledávání, sitemap.xml, robots.txt, canonical/hreflang, metadata.

MEDICÍNSKÉ UPOZORNĚNÍ: Obsah je redakční návrh a před aktivní propagací vyžaduje odbornou revizi. Není zdravotnickým poradenstvím.
